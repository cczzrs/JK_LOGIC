## 使用

需要 Node.js 22.12+，无 npm 依赖。在本项目根目录执行：

```sh
node skills/jk-network-generator/scripts/source.mjs
node skills/jk-network-generator/scripts/validate.mjs artifacts/jkrd-v4-skill-checks/mul-8x8.json
node --test skills/jk-network-generator/scripts/selftest.mjs
```

生成新模型和功能验证的命令见技能入口。业务规格独立于模型，结构合法与功能正确分别验收。现有模型报告保留原始内容和验证范围，不表示本次清理重新运行了全部算术穷举。

执行器提供同步任务边界；异步接收与保存请求的宿主调度、优化事件等价及通用状态模型仍需专门验收。标准快照保存状态与待执行任务，不保存外部 Xi 当前值和未收齐集合，不保证完整运行现场续跑。当前实现边界见实现契约。

## 研究方向（不代表已实现能力）

- 真正关键的命题是：
- 已经获得的结构，能否让系统用更少的搜索、修改和验证成本，获得新的结构能力？
- 验证的是一种不同的智能形成机制？
- 我究竟相信哪一种智能值得被创造？
- 从“我们制造它”，走向“它逐渐参与自身的构造”
```
可以重新相信的方向，是逐渐把其中一部分构造能力交给网络本身。
这不只是让它随机增删节点，也不只是允许它修改自己的文件。更实质的要求是：它能够把自己的结构当作理解和操作的对象。
例如，一个已有结构失败了。系统不只是保存“这次失败”，而是能够把失败与某个状态、依赖关系或执行顺序联系起来；发现缺少“等待某个条件”的环节，就从已有结构中组织出这个环节；以后遇到另一种任务时，复用的不只是那个等待模块，还包括“什么情况下需要这种结构”的关系。
```
- 形成这些功能的理由、组合这些功能的方法，以及改造这些功能的过程，不再全部由外部设计者掌握。
- 它是一条可以明确选择的设计方向：不满足于给系统安装能力，而是让系统逐渐参与能力的形成。
```
原来的设想里，有一个比“用逻辑节点替换神经元”更值得继续展开的部分：
记忆、计算、功能组合，都希望落到同一个结构体系中。
把它进一步变成设计原则，就是：
“知道一件事”，不只是存下一段描述；它应当能够改变系统在相应条件下的判断与行动。
“学会一种能力”，不只是挂上一个黑箱；系统应当能够利用它的组成关系，继续形成别的能力。
“理解自己的结构”，不只是把节点画出来给人看；有关结构的信息，也要能进入系统自己的计算过程。
```
- 知识能够成为可执行的结构，经验能够改变结构，而结构又能够参与新结构的形成。
- 愿景是你要创造的东西；JK 是你正在为它寻找的具体形态。
- 重新找到一个你真正认同的创造对象，让你知道自己究竟在往哪里走。
- 不是“一个装满功能的网络”，而是——一个逐渐能够参与构造自身能力的网络。

- 优化器：认知结构梳理（知识框架树形图、计算逻辑结构等）、EX 简化：除了真值表验证还需考虑触发机制以及状态数据存储等

## 视觉研究设想（未实现）

以下仅为需求与研究方向；具体结构须按中央 V4 规则设计并独立验证。

- 把每个像素的八个 bit 通过同编号有状态输入副本接入 JK，让 JK 跨位、跨像素计算局部特征，再把这些特征逐层组合。
```
位编号：     b7  b6  b5  b4  b3  b2  b1  b0
固定位值：  128  64  32  16   8   4   2   1
像素150：     1   0   0   1   0   1   1   0
```
- 3×3 RGB，每个颜色分量八位9×3×8＝216 bit
- 比较器 从低位向高位组合；当前位相同，就沿用低位比较结果；当前位不同，就由当前更高位决定结果。
```
差值需要 9 位有符号表示。例如：
100 − 80 = 20
80 − 100 = −20
```
- 局部特征可以有两种形式：
```
特征形式	示例	输出含义
布尔条件	R>L、中心是局部最大值	一个条件是否成立
多位数值	R−L、局部亮度和、对比幅度	一个有明确位序、范围的数值
```

- 一个节点输出一个 bit，并不限制一个特征只能输出一个 bit。 多个输出节点可以共同表达一个数值。
- 但“32 个独立布尔特征”和“4 个八位数值特征”虽然都占 32 个逻辑 bit，含义完全不同，后续计算不能混用。
- 可学习部分，负责决定观察哪些输入，以及怎样组合。
```
每个 3×3 RGB 窗口提供 216 个候选输入 bit。可以给每个局部特征提取器规定一个有限的 JK 结构，然后学习：
- 引用哪个像素、哪个数位。
- 使用 J 还是 K。
- 引用哪些前面节点的结果。
- 哪些局部结果继续组合成输出。
```
- ?前面的训练方式仍然适用：用操作评分、来源评分辅助优化，再导出确定的 ex 和连接。变化在于，输入具有完整的八位数值信息。?
- 其中有两个可分别验证的设计：
```
- 从基本 J/K 操作学习。 允许模型从输入位中发现有用组合，搜索自由度较大。
- 提供已验证的比较、差分等基础模块。 让训练选择比较哪些位置、使用什么关系、怎样组合；基础数值关系由结构保证。
```
- 引入了人工选择的结构先验。它仍需通过训练确定哪些组合对任务有用。
- 优先验证比较、方向和差分等关系?
- “输入是否保留”、“JK 是否学到有效特征”、“后续聚合是否丢掉必要细节”等。
